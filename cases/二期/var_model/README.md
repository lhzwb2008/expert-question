# 组合 VaR 模型回测选型

2026-11-11。二期第三题。8 只 ETF 组成的多资产组合，四个 99% 单日 VaR 模型做回测，定正式口径。

正式结果：采用 A 历史模拟法。C 指数加权法平均 VaR 最低，但突破 24 次，Kupiec 检验不通过。D 也合格，平均 VaR 比 A 高。

N=1464 时 Kupiec 的通过区间是 8 到 22 次突破。数据来自 Yahoo 复权日线，`fetch.py` 不需要账号。
