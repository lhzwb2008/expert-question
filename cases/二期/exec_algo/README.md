# 拆单算法选型

2026-11-11。二期第五题。招商银行 1 分钟行情上模拟四种拆单算法，每天买 200 万股，定默认算法。

正式结果：用 VWAP（对市场 VWAP 平均滑点 -0.67 bp，标准差 6.54 bp）。POV 平均滑点 -6.97 bp 最低，但标准差 40.84 bp。

分钟数据用 Longport 行情拉取，`fetch.py` 从本机 Quantra/.env 读密钥，文件里没有账号信息。成交量单位是手。

## 目录

- `attachments/`：输入附件，全部上传。
- `answer/`：标准答案附件，全部上传。
- `填写稿.md`：飞书各字段起草稿。`标准结果.md`：正式数字。
- `raw/`、`fetch.py`、`rebuild.py`、`summary.json`：只在本地用，不交给模型。
