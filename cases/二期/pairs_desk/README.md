# 配对交易候选对筛选

2026-11-11。二期第二题。8 对美股同行业股票，按 z 值开平仓的配对交易回测，定下上线哪一对。

正式结果：上线 XOM/CVX，净收益 2601.44，止损 2 次。GS/MS 净收益 3281.94 最高，但止损 6 次，超过 4 次的上限。

规则：价差 ln(A/B)，前 120 日均值和样本标准差算 z，|z|≥2 开仓，回到 0.5 以内平仓，到 4 止损，满 40 个交易日到期。数据来自 Yahoo 复权日线，`fetch.py` 不需要账号。
