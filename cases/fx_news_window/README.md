# GBP/USD 新闻过滤方案选择

2026-11-06。第四道题。数据是 Dukascopy 公开的 GBP/USD 1 分钟买价和卖价，日程是 BLS、美联储、英国央行官网的发布日历原文。不是自有策略。

## 要决定的事

P 平台的资助账户要上线一台伦敦开盘区间突破机器人。平台规定重大新闻前后 2 分钟不许开仓也不许平仓，违规交易的盈利扣除，第 3 笔违规终止账户。四个过滤方案里选一个。

正式结果：选方案 D（事件日停机）。A、B 都在第 3 笔违规时终止。C、D 都活到期末，可提现利润分别为 -30090.00 和 -28491.00 美元，D 更高。数字见 `answer/标准结果.md`。

## 和前三题比，改了什么

- 标的换成 GBP/USD，数据是买价、卖价的 1 分钟线，不是 QQQ，也不是沪金。
- 决策不是回测能不能上，而是四套新闻过滤怎么选。日程是官网原文，模型要自己认出哪一行算受限事件，并处理英美夏令时不同步。
- 2025 年 10 月美国政府停摆后，CPI 和非农的发布日改期，日程里已经是改期后的日期。按「每月第二个周五」去推会错。

## 没放进来的东西

没有券商账号，没有 Dukascopy 的拉取脚本。`raw/` 是买价、卖价的原始文件，只给 `rebuild.py --export` 用，不进输入附件。momentum 的参数没有进这道题。

## 怎么核对

```bash
python3 cases/fx_news_window/rebuild.py
python3 cases/fx_news_window/rebuild.py --export
```

`--export` 从 `raw/gbpusd_1m_A.pkl`、`raw/gbpusd_1m_B.pkl` 重写 A01。不带参数时只读附件。

2026-11-06 抽查过 2025-01-10：区间 1.22666 至 1.23081，UTC 12:24 按卖价 1.23124 做多，UTC 13:30 买价最低触及止损 1.22666，净盈亏 -1395.00，与台账一致。方案 C 同一笔在 UTC 13:25 平仓，净盈亏 9.00。
