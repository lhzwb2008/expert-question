# A05 是否开展

三个窗口分开统计，不要把不同 N 的收益加在一起。一个窗口同时满足下面四条才合格：

1. 做成的事件正好 15 笔。
2. 这 15 笔净收益之和大于 0。
3. 净收益大于 0 的笔数至少 8 笔。
4. 最差一笔净收益大于或等于 -0.05。等于 -0.05 算过，更差的一笔就不过。

三个窗口都不合格，结论是不开展。有合格窗口时，取得净收益之和最大的那个；和完全相同则取 N 较小的。

## 要交的三份材料

1. 事件表。每一笔一行，按生效日排序；同一天先写剔除栏、再写加入栏，栏内从左到右。列出生效日、加入或剔除、公司名称、开仓日，以及 N 为 1、5、10 的三个平仓日和三笔净收益。
2. 窗口汇总。三行，写明笔数、净收益之和、盈利笔数、最差一笔的公司和净收益、是否合格。
3. 建议。写开展或不开展。不开展时，三个窗口各自没有通过的那几条都要写上。开展时写明 N。

三份材料里的笔数、净收益和结论必须相同。
