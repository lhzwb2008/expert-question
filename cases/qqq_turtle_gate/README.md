# QQQ 日线海龟模拟盘准入

2026-11-04。这是本仓库的第一道题，后面出题先看这份，再另开 `cases/` 下的新目录。飞书题面、考点和标答不要整段从这里贴进去。

## 要决定的事

资管投研要决定：按冻结的日线和参数手册，2021-01-04 至 2026-10-30 这套日线海龟能不能签发模拟盘。三条门槛都过才签发，有一条不过就搁置。

实习生用收盘价、单一单位、不做 55 日入场、不设 2N 止损、不扣费用，得到期末权益 117402.57 美元，并建议签发。正式口径不采用这组数。

正式结果：期末权益 65476.19 美元，总收益 -34.5238%，收盘权益最大回撤 42.4577%（2026-04-10），手续费 217.56 美元，成交 331 笔。同一窗口买入持有收益 126.5737%，期末权益 226573.65 美元。三条门槛都未通过，结论是搁置。

## 平台要求

收的是上班时会拿去签字的活。做完要有动作：签发或搁置。做错会把不该开的模拟盘开出去。口头标准是：这件事交给豆包做完，本人肯付 100 元，自己做要超过 16 小时。

每次交齐：任务名称、任务类型、行业和职业、题面、输入附件、考点、作答思路、标准答案文字和附件。

难度两条都要过：

- SOTA 得分不高于 50。自测认豆包 2.1 Pro。
- 执行不少于 50 步，或运行超过 40 分钟。两条里过一条即可。排队、断网和自己暂停的时间不算。回答写得长，不等于跑了 50 步。

一次领 1 题。领了大约 8 小时内要交。本地先把材料和标答做完，再去表里领。

## 这道题怎么做出来的

1. 公开的「下载十年 QQQ，看看海龟失效了没有」不能交。数据源、复权、20 日还是 55 日一变，数就变了；没有写死的门槛，考点只能写成「做了评价」。
2. 行情用本地已有的 QQQ 1 分钟线，按交易日收成日线，评估窗和之前的回看都放进 A01。模型不许再下载。
3. 正式规则写进 A02。实习生的另一套算法和结果分别放进 A03、A06。费用在 A04。签发条件在 A05，写成可以判定的数。
4. 用 `rebuild.py` 把正式口径跑死，写入 `answer/`。标答、逐笔台账和每日权益用的是同一套数。
5. 题面只写角色、证据范围、冲突时以哪份为准、要交的三份材料。不写期末权益，不写「请看回撤」，不写考点。
6. 考点一条只查一件事，写明单位、误差，以及沿用实习生结果时记 0 分。

`rebuild.py` 只读分钟线并聚合成日线，不调用 Quantra 里的 `backtest.py`。那是另一套日内策略，不要放进这道题。

重算正式结果：

```bash
python3 cases/qqq_turtle_gate/rebuild.py
```

## 注意事项

不收纯代码、纯计算、纯摘要，也不收一次搜索就能完成的公开结论。海龟这个名字可以留在自己的笔记里，题名和题面不要写成「验证海龟是否失效」。

抽走任意一份 A01 至 A06，题应该就做不完。做得出，那份就是摆设。

坑放在规则和明细里，不要在题干里点破。A02 已经写了和 A03 冲突时以 A02 为准，题面再喊一遍「不要因为他赚钱就签发」，难度会掉。

备忘录、逐笔台账、差异清单里的期末权益、成交笔数和结论必须相同。对不上就不得分。

给模型的附件只有 `attachments/`。`answer/`、`rebuild.py`、这份说明、自测记录都不要放进输入附件。

考点、标答，以及「希望得分低于 50」不要出现在题面里。自测时新开一个会话，只贴题面和 A01 至 A06，中途不提醒它漏了哪条，也不帮它改计算。题面或附件改过，自测就重开。有一次高于 50，就改题，不要只留最低的那次。

Grok 可以用来检查材料缺不缺、标答能不能重算、题干有没有把坑写破。它的分数、步数和耗时不算质检结果。豆包 2.1 Pro 的自测还没做。2026-11-04 用 Cursor Cloud 的 Grok 4.7、思考档 Low 跑过一轮预估，记录在本地 `selftest/`，不入库。

平台不收能看出来是模型代写的题面、考点、附件和标答。`填写稿.md` 是起草稿，交表前用自己的话过一遍。

不要把券商账号、`.env`、Longport、IB 写进附件。模型没有这些登录，题会因缺材料作废。

这道题仍有被当成纯回测刷掉的风险：规则已经写进手册，强模型可能一轮写完程序就交卷，步数也不一定到 50。下一题要把冲突写进行情明细，让备忘录、台账、差异清单必须对上同一套数，而不是只交一个期末权益。

相邻的下一题至少改两处实打实的东西：场景、交付物、材料或决策对象。不要只把 QQQ 换成 SPY。
