# 商品跨期价差品种准入

2026-11-06。第五题。十八个国内商品的全部合约日线，判断哪些品种的期限结构够稳，可以放进跨期价差组合。

## 要决定的事

近月取到期最早、且持仓量和成交量够得着的合约。远月取近月之后持仓量最大的合约，不是下一个到期月，也不是成交量最大的合约。年化用两张合约的最后交易日之差。四条门槛都过才纳入。

正式结果：只纳入螺纹钢和铁矿石。螺纹钢升水，空近多远。铁矿石贴水，多近空远。豆油差在方向占比 80.45%，橡胶差在大波动日只有 54.70%，玻璃的曲线最陡但方向占比只有 64.69%。数字见 `answer/标准结果.md`。

## 和前四题比，改了什么

- 数据是十八个商品、884 张合约的日线，不是单一标的的分钟线。
- 决策是期限结构能不能做跨期，不是过滤方案，也不是模拟盘准入。
- 陷阱在远月怎么选、郑商所三位代码、最后交易日不按月末推算。

## 没放进来的东西

没有天勤账号，没有下单。乘数和最小变动价位在规格表里，题目写明四个指标都不用。`rebuild.py` 的 `--export` 只在本机重写附件，不交给模型。
