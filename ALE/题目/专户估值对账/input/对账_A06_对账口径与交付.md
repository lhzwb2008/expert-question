# 全球科技成长一号 2026年10月末估值对账口径

运营部，2026-11-02

全球科技成长一号是美元计价的单一资产管理计划，投资 8 只美股。管理人 2026 年 10 月上线新估值系统，新系统以 2025-10-31 日终持仓为起点，按一年的交易和资金流水重算了持仓和现金。2026-10-30 托管行复核时，双方的资产净值不一致。2026-10-30 也是年度业绩报酬计提日，计提前要先确定正确的资产净值。

## 一、重建范围

从 2025-10-31 日终（A01）开始，按 A02 逐笔记账，并处理 2025-11-01 至 2026-10-30 之间的公司行为，重建 2026-10-30 日终的：

1. 各股票持股数；
2. 现金余额；
3. 应收股利、应收退税；
4. 资产净值 = 股票市值 + 现金 + 应收股利 + 应收退税。股票市值按 A03 中 2026-10-30 的不复权收盘价计算。

管理费、托管费另行计提，不在这次对账范围内。

## 二、公司行为

1. 拆股和现金分红没有内部记录。A07 是 8 只股票的 Yahoo Finance 日线导出，其中 Dividends、Stock Splits 两列是公司行为记录。每股分红按发行人实际派发的金额入账；导出数据与托管行入账（A05）对不上的，查明原因后再入账。
2. 拆股在生效日开盘前生效，持股数乘以拆股比例。生效日及以后的交易按拆股后的股数和价格记录。
3. 现金分红按除息日前一交易日日终的持股数享有。除息日确认应收股利，付息日收到现金时冲减。
4. 除息日在 2025-11-01 至 2026-10-30 之间的分红计入本期。TXN 2025-10-31 除息的股利已在期初列为应收股利（见 A01），付息时冲减。
5. 本计划适用税收协定，美国股息预提所得税税率为 10%。应收股利、已收股利都按税后金额记录。托管行实际扣税超过 10% 的部分记为应收退税，列入资产。
6. 付息日以 A05 的入账日期为准。到 2026-10-30 日终还没到账的，列应收股利。

## 三、交易与费用

1. A02 中的成交价就是当日收盘价。
2. 佣金为成交金额的 0.02%；卖出另收 SEC 交易费，为成交金额的 0.00278%。
3. 买入付出 = 成交金额 + 佣金；卖出收到 = 成交金额 − 佣金 − SEC 交易费。
4. 申购款到账当日计入现金。
5. 成交金额、佣金、SEC 交易费、税前股利、预提税逐笔四舍五入到美分，再汇总。税后股利 = 税前股利 − 预提税。

## 四、差异与差错

1. 重建结果分别与管理人新系统估值表（A04）、托管行对账单（A05）逐项比较：各股票持股数、股票市值、现金、应收股利、应收退税、资产净值。每项差异写明金额、原因、责任方和更正方式。
2. 估值差错率 =（管理人估值表资产净值 − 重建资产净值）÷ 重建资产净值，以百分数列示，保留两位小数。判断处理级别时用未舍入的数值。
3. 按公司估值差错处理办法：
   - 差错率绝对值低于 0.25%：更正估值，并通报托管行；
   - 达到 0.25%、低于 0.50%：更正估值，通报托管行，并报告监管机构；
   - 达到 0.50%：除上述各项外，还要对外公告。

## 五、要交的文件

### 《专户估值对账表.xlsx》

四个工作表：

- 「持仓重建」：8 只股票各一行，顺序同 A01。列明期初股数、拆股增加的股数、本期买卖股数、2026-10-30 重建股数、收盘价、市值，以及管理人、托管行各自的股数和与重建的差异。
- 「股利明细」：本期每次分红一行，按除息日排序。列明代码、除息日、享有分红的股数、实际每股分红、A07 导出的每股金额、税前金额、应扣税款、税后应收、付息日、托管行代扣税款和实收、多扣税款、10-30 是否到账。
- 「净值汇总」：重建、管理人、托管行三列，分别列股票市值、现金、应收股利、应收退税、资产净值；另列差错率和处理级别。下一步计提业绩报酬直接用这里的重建资产净值。
- 「公司行为」：用到的拆股和分红记录，每条注明来源文件；注明 A07 各文件的查询时间、代码、工具和参数，以及对导出分红金额做过的处理。

### 《专户估值对账报告.docx》

发运营部、托管行和投资经理。写明：正确的资产净值；管理人新系统的每项差错及金额、原因和更正方式；托管行的每项差异；差错率和处理级别；公司行为数据的来源和处理。

金额以美元列示，保留两位小数；股数为整数。两份文件里的资产净值、差错率、处理级别和各项差异金额要一致。
