# 哪些变动纳入测算，持有几天

从成份股变动汇编里挑。公司名称按汇编原文对代码表，不改写，不按字面相近合并。

一条变动同时满足下面四条，才纳入：

1. 生效日在 2020-09-07 至 2026-09-07，含两端。
2. 备注写明是指数检讨结果。私有化、改名、并购、分拆不纳入。
3. 加入或剔除的公司，在代码表里能对上同一行，并且 A 股代码和 H 股代码都有。只有一边的跳过。
4. 同一格里有多家公司时，从左到右拆开，每家单独判断。同一家先后被剔除和加入，各算一笔。

开仓日是生效日之前最近的一个共同交易日，按收盘价成交。

平仓日从生效日当天起算。生效日本身如果是共同交易日，它是第 1 个；向后只数共同交易日，数到第 N 个，按那天的收盘价平仓。三个窗口的 N 是 1、5、10。开仓日不算进这 N 天。

凑不齐开仓日，或凑不齐第 N 个共同交易日的，这一笔在这个窗口里不做。
