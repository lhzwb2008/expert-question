# 是否开展

三个窗口分开统计，不同 N 的收益不加在一起。一个窗口同时满足下面四条才合格：

1. 做成的事件正好 15 笔。
2. 这 15 笔净收益之和大于 0。
3. 净收益大于 0 的笔数至少 8 笔。
4. 最差一笔净收益大于或等于 -0.05。等于 -0.05 算过，更差的一笔就不过。

三个窗口都不合格，结论是不开展。有合格窗口时，取净收益之和最大的那个；和完全相同则取 N 较小的。

## 交付

提交四份。四份里的笔数、净收益和结论必须相同。

1. **行情核对记录**：快照里每只代码的行数和起止日期；考察期内每条纳入变动用到的代码，快照里有没有；供应商导出的覆盖范围、日期怎么对到交易日、价格是不是不复权，以及测算实际用的价格。
2. **变动取舍表**：生效日落在考察期内的每一条加入或剔除各占一行，按生效日排序，同一天先剔除、后加入，栏内从左到右。列出公司名称、纳入或不纳入、不纳入的原因。
3. **事件测算表**：纳入的每一笔一行，排序与取舍表里纳入的行一致。列出生效日、加入或剔除、公司名称、开仓日，以及 N 为 1、5、10 的三个平仓日和三笔净收益。另附窗口汇总：三行，写明笔数、净收益之和、盈利笔数、最差一笔的公司和净收益、是否合格。
4. **开展建议**：写开展或不开展。不开展时，三个窗口各自没有通过的那几条都要写上。开展时写明 N。
