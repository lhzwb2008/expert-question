# A03 产品要素与交付

## 产品要素

| 项目 | 内容 |
| --- | --- |
| 产品类型 | 投资港股的红利产品（QDII），人民币募集，资产以港元持有 |
| 募集金额 | 人民币 800,000,000 元 |
| 建仓基准日 | 2026-10-30，按当天收盘价测算 |
| 管理费 | 每年 0.75%，按产品资产计提 |
| 托管费 | 每年 0.15%，按产品资产计提 |
| 现金 | 股票仓位目标为产品资产的 95%，其余和取整剩下的部分留作现金 |

## 年度分配目标

产品合同里要写一个年度分配目标，用产品资产的百分比表示，只能从 4.0%、4.5%、5.0% 三档里选。

- 可分配能力 = 税后股息率 − 管理费率 − 托管费率。
- 年度分配目标取不超过可分配能力的最高一档。
- 可分配能力低于 4.0% 时，不设年度分配目标。

结论四选一：「4.0%」「4.5%」「5.0%」「不设年度分配目标」。

## 要交的内容

提交两份文件，两份里的建仓股数、现金、税后股息率和分配目标必须相同。

1. 建仓方案表。四个工作表：
   - 「目标权重」：15 行，顺序同筛选表的「入选名单」。每行写行业、近 12 个月股息率、初始权重、目标权重，以及是否因为单只上限或行业上限被调整。
   - 「建仓清单」：15 行，顺序同上。每行写每手股数、基准日收盘价、目标金额、建仓股数、手数、建仓市值、实际权重、税务类别、预提税率、税后年股息。
   - 「汇总」：汇率、产品资产、股票仓位目标、建仓市值合计、现金、现金占产品资产的比例、税后年股息合计、税后股息率、可分配能力、年度分配目标。
   - 「在线数据」：通过在线查询得到的汇率和查询信息。
2. 建仓方案说明。写明年度分配目标和依据，税后股息率和可分配能力，产品资产、建仓市值合计和现金，哪些股票、哪些行业触及上限以及调整后的权重，三类税务类别各自的税后年股息合计。

金额保留 2 位小数，权重和百分比保留 4 位小数，股数和手数为整数。
