# 中证500ETF内部行情快照价格口径核验记录

## 一、核验目的
10月末存续排查取数前，按《雪球收益凭证业务管理与月末存续排查办法》第十五条，对内部行情快照里中证500ETF（510500）的价格口径、除息资料和台账期初价格做一次全面核对。快照经 LongPort 通道每日落地，同时保存不复权和前复权两套收盘价，排查只用不复权价。

## 二、不复权价与前复权价的差额
前复权价等于不复权价减去该日之后各次现金红利的累计数。按交易日逐日计算两者差额，差额只在除息日发生跳变，跳变幅度就是当次每份红利。核验区间 2022-09-09 至 2026-10-30，共 1000 个交易日：

| 区间 | 不复权价 − 前复权价（元） | 较上一段减少（元） |
| --- | --- | --- |
| 2022-09-09 至 2024-05-16 | 0.389 |  |
| 2024-05-17 至 2025-01-15 | 0.302 | 0.087 |
| 2025-01-16 至 2026-01-15 | 0.211 | 0.091 |
| 2026-01-16 至 2026-07-14 | 0.149 | 0.062 |
| 2026-07-15 至 2026-10-30 | 0.000 | 0.149 |

四次跳变分别落在 2024-05-17、2025-01-16、2026-01-16、2026-07-15，减少额 0.087、0.091、0.062、0.149 元，与运营部除息记录逐笔一致，累计 0.389 元。2022-09 以来没有发现除息记录以外的差额变化。

## 五、与指数走势的一致性
抽查 2026-10-08 至 2026-10-30 共 17 个交易日，中证500ETF不复权日涨跌与中证500指数日涨跌之差的绝对值平均 0.097 个百分点，最大 0.300 个百分点，没有错日或缺日迹象。10月快照共 17 个交易日，国庆假期后首个交易日为 2026-10-08，与交易所日历一致。

## 六、结论与后续
1. 内部快照中证500ETF的不复权收盘价、除息资料和台账期初价格三者一致，可直接用于10月末排查。
2. 中证1000ETF不在快照覆盖范围内，按办法第十五条在线补取。数据组提醒：在线服务的价格口径、日期字段格式和内部快照不一定相同，取回后先用台账里5张中证1000ETF凭证的期初价格逐笔对上，再进入排查；核对过程写进排查表「在线数据」。
