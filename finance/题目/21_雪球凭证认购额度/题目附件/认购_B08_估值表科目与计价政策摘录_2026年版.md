# 多策略稳健1号估值表科目与计价政策摘录（2026年版）
来源：《多策略稳健1号会计核算与估值手册》（2026年版，2026-01-05生效）第二章、第三章　摘录：林晓雯　审核：唐卫东

## 一、估值表结构
估值表按估值日编制，列科目代码、科目名称、市值（元）、市值占净值比例和备注。资产类在前，负债类在后，最后列资产合计、负债合计和资产净值。估值表摘要只保留一级科目和需要单独列示的明细，买入返售按笔列示。

## 二、资产类科目
| 代码 | 名称 | 含义与计价 |
| --- | --- | --- |
| 1002 | 银行存款 | 托管账户活期存款余额，按账面余额计价 |
| 1021 | 结算备付金 | 存放在登记结算机构的结算备付金，按余额计价 |
| 1031 | 存出保证金 | 交易所交易保证金、期货保证金，按余额计价，不能随时动用 |
| 1103 | 债券投资 | 交易所和银行间债券，按估值机构提供的估值计价 |
| 1108 | 收益凭证投资 | 券商收益凭证，按发行人估值计价，名义本金另在台账登记 |
| 120201 等 | 买入返售金融资产 | 交易所或银行间逆回购，按成本列示，备注买入日和到期日 |
| 1204 | 应收利息 | 债券、存款、逆回购的应计未收利息 |

| 代码 | 名称 | 含义 |

| 2203 | 应付赎回款 | 开放日已确认、尚未支付的赎回款，备注支付日 |

## 四、资产净值和比例
资产净值 = 资产合计 − 负债合计。估值表的「市值占净值比例」以资产净值为分母，资产合计因含负债对应的资金，占比会超过100%。

## 五、与雪球限额的关系
1. 雪球限额按名义本金计算，不用「收益凭证投资」的市值。估值低于名义本金是挂钩ETF下跌、凭证估值下降的结果，并不减少额度占用。
2. 现金类资产按《现金类资产口径与流动性管理说明》计算，要逐笔看买入返售的到期日。
3. 应付赎回款按备注的支付日判断是否在认购缴款日之前或当日支付。

## 六、使用估值表时容易出错的地方
1. 把「收益凭证投资」的市值当成名义本金。市值随挂钩ETF涨跌变化，名义本金只在认购、敲出或到期时变化。
2. 把资产合计当成分母。限额和比例的分母都是资产净值。
3. 把存出保证金当成可用资金。它是交易所和期货公司的保证金，不能用于缴款。
4. 只看买入返售的科目合计，不看每笔的到期日。
5. 忽略应付赎回款的支付日。已确认的赎回款会在支付日减少可用资金。

## 七、版本关系
本摘录替代2025年版手册相关章节。2025年版的估值表摘要把买入返售合并为一行，2026年起按笔列示并备注到期日。
