# A04 哪些变动算事件，持有几天

从 A06 里挑事件。公司名称按原文匹配 A07，简体和繁体不要混用，也不要按字面相近去猜。藥明生物不是藥明康德，比亞迪電子不是比亞迪股份，中國電訊不是中國電信，國藥控股没有对应的 A 股。

一条变动同时满足下面四条，才可能产生事件：

1. 生效日在 2020-09-07 至 2026-09-07，含两端。更早的纳入、剔除、改名、分拆都不做。
2. 备注里有「指數檢討」四个字。私有化、改名、并购、分拆不要做。2026 年 1 月恒生银行那一行没有这四个字。
3. 加入栏和剔除栏里的公司，到 A07 能找到同一行，并且 A 股代码、H 股代码都不是空的。只有一边代码的公司跳过。
4. 同一格里有多家公司时，按从左到右拆开，每家单独判断。第二次列入、第二次剔除也算，中国神华的剔除和后来的加入是两笔。

开仓日是生效日之前、最近的一个共同交易日，按收盘价成交。

平仓日从生效日当天起算。生效日本身如果是共同交易日，它是第 1 个；向后只数共同交易日，数到第 N 个，按那天的收盘价平仓。三个窗口的 N 分别是 1、5、10。开仓日不要算进这 N 天。

凑不齐开仓日，或凑不齐第 N 个共同交易日的，这一笔在这个窗口里不做。
