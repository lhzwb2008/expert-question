# A05 准入和交付

一个品种纳入组合，当且仅当下面四条同时成立。差一条就不纳入。

1. 配对覆盖率 ≥ 95%。配对覆盖率 = 成功配出近月和远月的交易日数 / 该品种的交易日数。
2. 大波动日占比 ≥ 60%。大波动日是年化展期的绝对值大于或等于 0.03 的配对日。占比的分母是该品种的交易日数，不是配对日数。
3. 方向占比 ≥ 85%。在大波动日里，年化展期大于 0 的天数和小于 0 的天数，取较大的那个，除以大波动日天数。
4. 年化展期中位数的绝对值 ≥ 0.03。中位数：把全部配对日的年化展期从小到大排列。奇数条取正中间一条；偶数条取正中间两条的算术平均。

比例用原始分数和门槛比较，不要先四舍五入成百分数再比。

纳入之后看中位数的符号。中位数为正，记贴水，组合做多近月、做空远月。中位数为负，记升水，组合做空近月、做多远月。未纳入的品种不写方向。

## 要交的三份材料

1. 品种判定表。十八行，按 A03 的品种顺序。每行写品种代码、交易日数、配对日数、大波动日数、年化大于 0 的大波动日数、年化小于 0 的大波动日数、中位数（6 位小数）、是否纳入、方向。
2. 纳入品种的逐日台账。每个纳入品种在窗口内的每一个成功配对日写一行：日期、近月代码、远月代码、两个收盘价、两个最后交易日、间隔自然日、年化展期。未纳入的品种不写逐日台账。
3. 组合建议。写明纳入哪些品种、各自的方向，以及没有纳入的品种里最容易被误选的三个：豆油、天然橡胶、玻璃，各用一条不过的门槛说明原因。

三份材料里的纳入名单和方向必须相同。
