# 行情数据供应商比选方案

- 编制：数据组 程悦
- 审核：投研负责人 顾岩
- 日期：2026-04-08
- 依据：2026Q1 评审会议题 2026Q1-03「行情数据供应商比选立项」

## 一、背景

产品线研究库的境外行情目前来自供应商丁的终端产品，合同 2026-09-30 到期。终端产品不含 API 批量下载，研究库的境外日线和分钟线靠每日人工导出后入库，2025 年因人工导出遗漏出过三次数据缺口。本次比选的目标是在合同到期前选定一家能通过 API 稳定提供研究用行情的供应商。

本方案中的供应商一律用甲、乙、丙、丁代称，名称和联系人记录在采购部门的供应商档案里，不在研究材料中出现。

## 二、范围

需要的数据：

1. A 股、港股、美股的日线和 1 分钟线，含开高低收、成交量、成交额；
2. 主要汇率的日线；
3. 境内商品期货主力和各月合约的日线；
4. 分红、拆股等公司行为记录；
5. 交易日历。

不在本次范围：Level 2 行情、实时推送行情（交易用行情由券商和交易所渠道提供，不受本次比选影响）、财务数据、另类数据。

## 三、参与方

邀请四家：甲、乙、丙，以及现用供应商丁。丁可以按新的需求重新报价。

## 四、评分口径

评分满分 100 分，六个维度，权重如下：

| 维度 | 权重 | 评价要点 |
| --- | --- | --- |
| 数据覆盖 | 25 | 第二节所列数据是否齐全，历史回溯年限 |
| 数据质量 | 25 | 缺失、重复、异常值，公司行为的处理方式和说明 |
| 接口与稳定性 | 15 | API 限流、断线重连、历史数据批量下载 |
| 合规与授权 | 15 | 研究、内部报告的使用范围，是否允许入库长期保存 |
| 服务 | 10 | 工单响应时间、数据更正的通知方式 |
| 费用 | 10 | 三年总费用，费用越低得分越高 |

评分人：数据组、海外策略组、集中交易室各一人，独立打分后取平均，四舍五入到整数。评分人不得事先交流分数。评分记录由数据组归档，采购审批前交合规部。

## 五、数据质量的评价方法

各家提供两周试用账号。数据组在试用期内做三类检查：

1. 抽样比对：选若干标的、若干交易日，与公司已有的数据来源比对收盘价和成交量。
2. 公司行为：抽查 2025 年以来的分红、拆股记录，看是否齐全，复权方式是否写明。
3. 交易日历：比对 2026 年各市场的休市安排。

为了确认抽样比对的方法本身可行，数据组先用公司已有的两个来源做一次基准抽检：LongPort 行情接口（公司境外交易账户附带的行情权限）和 Yahoo Finance 公开数据。抽检选样本期内没有分红、拆股的美股，避免两边复权处理不同造成的差异。基准抽检结果见 A03。如果两个已有来源本身一致，试用期就用它们作为比对基准。
