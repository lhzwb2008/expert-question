## 一、申请内容

采购供应商乙的研究用行情 API 服务，服务期三年（2026-07-01 至 2029-06-30），2026 年 7 月起与现用供应商丁并行，2026-09-30 丁的合同到期后由乙单独提供。

三年总费用在比选四家报价中处于中间区间，低于甲，高于丙。具体金额见采购部门的合同审批单，本记录不列。

## 二、选择理由

评分结果（A02「评分结果」，三名评分人独立打分后取平均）：

| 供应商 | 合计 |
| --- | --- |
| 甲 | 81 |
| 乙 | 82 |
| 丙 | 75 |
| 丁（现用） | 71 |

乙合计分最高。甲的数据覆盖和质量分略高，但费用分低；乙的接口与稳定性得分更高，试用期两周内没有断线，可以直接接入现有行情网关。丙的美股分钟线回溯只有两年，授权范围在 5 月 6 日的书面答复中仍只写研究用途，不含内部报告。丁的 API 方案需要部署由对方远程维护的本地服务器，信息技术部的信息安全初步意见是需要额外评估，周期不确定。

## 四、合同要点（签约后补记，2026-06-12）

1. 服务期 2026-07-01 至 2029-06-30。
2. 授权范围：公司内部研究和内部报告。对外展示须另行书面同意。
3. 数据更正：供应商发现数据错误后通过邮件和更正日志通知。
4. 合同终止后，已入库的历史数据可以继续用于内部研究，不得对外提供。
5. 服务水平：交易日 API 可用率不低于约定水平，未达标按约定减免费用。
