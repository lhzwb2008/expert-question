# 排程差异处理与补排规则说明

整理：交易部、合规风控部，2026-10-30。用于排程执行中出现偏差时的处理。本说明是排程口径的配套规则，与排程口径同时生效。

## 一、什么算差异
- 实际成交与当日计划股数不一致（多卖或少卖）；
- 实际卖出节奏与排程不同（提前卖完或拖后）；
- 卖出了排程里没有的股票，或在解禁日前卖出。
节奏不同但每天都在单日上限和当天额度内的，不算违规，只在复核时说明。

## 二、补排规则
1. 某日实际少卖，剩余量不自动结转到次日叠加，次日仍按单日上限和当天额度排；确需赶进度的，由交易部报风控后在不超单日上限、不超额度的前提下补排。
2. 某日因额度受限只能卖一部分的，按当天剩余额度向下取整到 100 股卖，差额等窗口放额后的交易日再卖。
3. 解禁日之前不得排入卖出；解禁日当天起按正常规则排。
4. 临时停牌当日不排，停牌结束后顺延；顺延后仍按原单日上限，不因停牌加量。
5. 月末仍有剩余持股的，不跨月结转计划，下月重新排程。

## 三、超限处理
- 单日卖出超过单日上限：当日立即停止该只卖出，报风控，次日起按排程；
- 90 日窗口累计超过 1% 额度：违反投委会纪律，报合规负责人和投委会，窗口回到额度内之前暂停该只卖出；
- 卖了名单外股票：立即停止，报合规负责人，查明是指令错误还是系统参数错误；
- 成交价不在当日最低价和最高价之间：先按回报金额入账，要求交易部向券商核对更正。

## 四、差异记录与上报
1. 交易部每日收盘后把当日实际成交与排程计划的差异登记在执行台账，列股票、计划股数、实际股数、差额、原因；
2. 差异属节奏不同但未超限的，归入执行回顾，不单独上报；
3. 差异属超单日上限、超 90 日额度、卖了名单外股票、成交价不在当日区间的，当日报风控，风控判定是否违规并提出处理；
4. 半月或月度执行复核时汇总全部差异，对违规项逐条给出处理意见，报投资经理、交易部和合规负责人。

## 五、几种常见情形的处理
| 情形 | 处理 |
| --- | --- |
| 某日少卖 | 次日不叠加，仍按单日上限与当天额度排 |
| 某日因额度只卖一部分 | 按当天剩余额度向下取整到 100 股卖，差额等放额后再卖 |
| 尾日卖完 | 最后一天按剩余持股卖，可能小于单日上限 |
| 解禁日在月中 | 解禁日之前不排，解禁日起按正常规则排 |
| 盘中流动性骤降 | 执行端降速，不改排程上限，少卖部分不结转 |
| 个股临时停牌 | 当日不排，复牌后顺延 |

## 六、时限
| 事项 | 时限 | 责任 |
| --- | --- | --- |
| 当日差异登记 | 收盘后 1 小时内 | 交易部 |
| 超限上报 | 发现后 30 分钟内 | 交易部、风控 |
| 违规判定与处理意见 | 次一交易日开盘前 | 风控 |
| 补排申请审批 | 当日 14:00 前提出，风控当日答复 | 交易部、风控 |
