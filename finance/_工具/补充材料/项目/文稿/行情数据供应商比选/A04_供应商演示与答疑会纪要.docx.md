# 行情数据供应商演示与答疑会纪要
## 会议信息
时间：2026-04-22 09:30 至 17:00，四家依次进行，每家约 90 分钟。地点：12 楼小会议室，供应商丙为视频方式。
公司出席：数据组程悦（主持），海外策略组韩屿，集中交易室邵川，信息技术部苏禾。合规部许棠出席下午两场。记录：数据组。
按比选方案，本纪要用甲、乙、丙、丁代称，不写供应商名称和对方人员姓名。
## 一、基准抽检结果通报（会前内部）
程悦通报基准抽检：用 LongPort 行情接口和 Yahoo Finance 公开数据，对样本期内没有分红、拆股的两只美股（AMZN、TSLA）比对 2026 年 1 月以来的日线。两边收盘价一致，成交量差异很小。结论是这两个来源可以作为试用期抽样比对的基准。抽检将随样本期延长持续补充，最终样本截至 5 月底（A03）。
## 二、供应商甲
演示终端和 API 两种形态。API 支持历史数据批量下载，单次请求上限较高。数据覆盖最全，含港股 Level 2（本次不需要）。
答疑：公司行为提供不复权、前复权、后复权三种价格，复权因子单独提供。境内商品期货的各月合约日线可以回溯十年以上。
关注点：报价最高；账号按人头计，研究员增加时费用随之上升。授权范围包括研究和内部报告。
## 三、供应商乙
只提供 API，没有终端。覆盖第二节所列全部数据，不含港股 Level 2。
答疑：限流按每分钟请求数计，批量下载走单独通道，不占限流。数据更正通过邮件和接口的更正日志同时通知。对外展示（例如给投资者的材料）不在默认授权范围内，需另议。
关注点：API 文档完整，试用期两周内没有出现断线。苏禾确认重连机制可以直接接入现有行情网关。
## 四、供应商丙
按调用量计费，没有账号数限制。美股分钟线只回溯两年，超过两年要单独购买历史包。
答疑：公司行为记录齐全，但复权方式在文档里没有写明，对方答复后续补充。授权范围只写了研究，内部报告是否包含没有明确答复。
关注点：许棠认为授权范围不明确是硬伤，合同里必须写清楚。
## 五、供应商丁（现用）
重新报价后提供 API 批量下载，但需要另外部署一台本地服务器，由对方远程维护。
答疑：API 和终端的数据是同一来源。远程维护需要开放外网访问，苏禾表示要走信息安全评估。
关注点：过去一年三次数据缺口都与人工导出有关，对方认为 API 可以解决；但本地服务器方案增加了运维和信息安全工作量。
## 六、讨论

邵川：集中交易室用到的是交易日历和分钟线，交易日历四家都没有问题。
程悦：评分在 4 月 30 日前完成，评分人不交流分数。合计分接近时，按比选方案以评分为准，不另设加分。
