# 【已废止】雪球报价历史回测与比选口径（2026年9月征求意见稿）
【已废止】本版自2026-10-21起由《11月新增雪球凭证报价回测和入选规则》（投委会2026年10月例会通过）替代，征求意见的处理情况见第三部分。

起草：投资经理 周启明、量化研究部 韩笑　发出：2026-09-22　征求意见截止：2026-09-30　征求范围：风险管理部、交易部、合规、投委会委员

## 一、起草背景
9月18日投委会临时会议暂停9月新增批次，要求在10月例会前提出以历史回测为基础的比选办法。本稿是第一版设想，供各部门提意见。

## 二、拟定口径
1. **回测窗口**：近五年，即2021-10-01至2026-09-30。内部行情快照从2022-09-09开始，之前的部分由信息技术部数据组补取。
2. **价格**：挂钩ETF不复权收盘价，按合同约定逐次做除息调整，和月末存续排查完全一致。
3. **起始日**：每周第一个交易日开一张，到期日晚于窗口末的不计。
4. **观察和判断**：与月末存续排查相同。敲入后到期前的观察日即使收盘高于敲出价格，也按敲入处理，以保守估计风险。
5. **收益指标**：平均收益率 ÷ 平均持有天数 × 365，作为每份报价的「组合年化收益」。
6. **门槛**：敲入亏损比例不超过10%，固定不变。
7. **入选**：符合门槛的报价按组合年化收益排序，每批选前两名，额度平均分配。

## 三、征求意见汇总
| 提出人 | 意见 | 处理 |
| --- | --- | --- |
| 风险管理部 何嘉怡 | 五年窗口只覆盖2022年和2024年初两段下跌，2015年、2018年都不在内，敲入风险会低估 | 采纳，改为十年 |
| 风险管理部 何嘉怡 | 不复权价加逐次除息调整工作量大，十年数据里的分红记录也不全，建议改用按分红调整过的价格 | 采纳 |
| 风险管理部 沈文澜 | 固定门槛与存量脱节，建议与月末存续排查的敲入占比挂钩分档 | 采纳，分两档 |
| 量化研究部 许诺 | 每周一张样本太少，且结果受星期效应影响，建议每个交易日一张 | 采纳 |
| 量化研究部 许诺 | 敲入后又敲出的凭证实际拿回了票息，按敲入处理与合同不符 | 采纳，按敲出计 |
| 量化研究部 韩笑 | 「组合年化」会被持有期长短不同的凭证拉偏，建议逐张年化后取平均 | 采纳 |
| 交易部 郭振华 | 每批只选前两名、平均分额度，会浪费额度较大发行人的报价 | 采纳，入选的全部排序，按顺序分额度 |
| 交易部 赵一鸣 | 部分发行人报价有效期只有一天，回测须在最终报价当日或次日完成 | 纳入工作安排 |
| 合规 吕婧 | 门槛和排序规则应写进正式口径文件，执行时不得临时调整 | 采纳 |
| 投资经理 周启明 | 建议保留票息作为并列排序因素 | 未采纳，例会决定只按平均年化收益率排序 |
