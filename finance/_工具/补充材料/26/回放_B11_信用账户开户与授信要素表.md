# 量化多头二号 融资融券信用账户开户与授信要素表

归档：运营部。最后更新：2026-06（合同续签时同步更新）。用途：登记信用账户的开户和授信基础要素，供日常对账和复核时查阅。本表登记静态要素，逐日的持仓、负债和担保比例以每日对账单为准。

## 一、账户基本信息

| 项目 | 内容 |
| --- | --- |
| 产品 | 量化多头二号 |
| 券商 | 华东证券 |
| 账户类型 | 融资融券信用账户 |
| 首次开户 | 2025-06 |
| 现行合同 | 2026-06 续签版（见《回放_A04_融资融券合同条款摘要.md》） |
| 合同期限 | 一年，到期续签 |
| 用途 | 融资买入沪深担保证券，不做融券卖出 |

## 二、授信与费率要素（现行续签版）

| 项目 | 内容 |
| --- | --- |
| 授信额度 | 融资授信总额度 5,000 万元（内部按不超过产品净值的一定比例控制实际使用） |
| 融资年利率 | 6.20%，一年按 360 天 |
| 计息方式 | 逐自然日计息，周末、节假日照计；节假日按节前最后一个交易日日终本金计 |
| 结息 | 每季度末月（3、6、9、12 月）的 20 日结息 |
| 佣金 | 成交金额的 0.025%，每笔不低于 5 元 |
| 过户费 | 成交金额的 0.001%，买卖都收 |
| 印花税 | 成交金额的 0.05%，卖出时收 |
| 警戒线 | 日终维持担保比例低于 150%，次日通知，恢复前暂停新增融资买入 |
| 追保线 | 日终维持担保比例低于 130%，次日发追保通知，T+2 日日终前补回 150% 以上 |
| 强制平仓 | 追保逾期自 T+3 日起，先用现金直接还款，再卖券，以恢复 150% 为限 |

> 开户时（2025-06 版）年利率为 6.50%、按交易日计息、追保期限 T+3 补回 130%、佣金 0.030%，均已在 2026-06 续签时调整。旧版要素见《回放_B05_融资融券合同条款摘要_2025年6月版（已废止）》。

## 三、担保证券与计算口径

- 担保证券范围：沪深两融标的证券。当前持有宁德时代、中芯国际、紫金矿业、中信证券、美的集团、中国平安六只。
- 维持担保比例 =（现金余额 + 担保证券市值）÷（融资本金 + 应付利息）。担保证券市值按日终持股数 × 当日不复权收盘价计算，券商每个交易日日终算一次。
- 折算率、融资保证金比例只用于可充抵保证金和可融资额度管理，不参与维持担保比例的计算（见《回放_B04_担保证券折算率与融资保证金比例表_2026年9月（内部整理）》）。

## 四、对账与通知流程

- 运营岗每个交易日日终与华东证券核对持仓、本金、利息、现金，差异当日处理（见 B01、B03 的 9 月对账留档）。
- 券商通知（警戒、追保、强平）到达后，合规风控部按合同条款逐条复核，再决定处置，不直接采信券商算的比例。

## 五、备注

本表与合同条款如有不一致，以合同为准。要素调整随合同续签同步更新；本表只登记现行与紧邻的上一版要素，更早的版本不在此登记。
