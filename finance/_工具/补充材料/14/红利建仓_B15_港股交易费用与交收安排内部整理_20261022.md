# 港股交易费用与交收安排（内部整理）

整理：刘洋（运营部）、交易室　日期：2026-10-22　用途：建仓下单前的费用预估和资金交收安排

> 说明：本文是本公司根据券商经纪服务协议条款和与券商销售交易部的电话沟通整理的内部材料，不是券商出具的文件。费率以经纪服务协议和券商结算单为准。按投委会决议和建仓口径，**建仓测算不考虑交易费用和冲击成本**，本文只用于下单阶段的资金准备。

## 一、买入港股的费用构成

| 项目 | 收取方 | 费率或标准（整理时口径） | 说明 |
| --- | --- | --- | --- |
| 经纪佣金 | 券商 | 按协议约定的成交金额比例 | 本产品协议费率另行约定，按月结算 |
| 印花税 | 香港特区政府 | 成交金额的 0.1%，买卖双方各付，不足 1 港元按 1 港元计 | 按每张合约单据计 |
| 交易征费 | 香港证监会 | 成交金额的 0.0027% | |
| 会财局交易征费 | 会计及财务汇报局 | 成交金额的 0.00015% | |
| 交易费 | 香港交易所 | 成交金额的 0.00565% | |
| 股份交收费 | 香港结算 | 按成交金额的比例收取，设最低和最高收费 | 由券商代收，以结算单为准 |

以上费率是整理时的口径，若有调整以实际收费为准。

## 二、交收安排

1. 港股交收为 T+2。11-02 下单成交的股票在 11-04 交收，境外托管账户要在交收日前备足港元。
2. 本产品通过境外托管人持有股票，券商与境外托管人之间按 DVP（券款对付）方式交收。交易室每天收市后把成交回报发运营部，运营部次日上午向托管行发送交收指令。
3. 购汇在 11-02 办理，港元到账时间以托管行通知为准。若购汇资金未到，交易室当日下单金额不超过已到账港元。

## 三、下单与碎股

1. 港股按每手股数买卖，下单数量必须是每手股数的整数倍，不足一手的碎股只能在碎股市场买卖，价格通常不利。建仓股数按建仓口径向下取整到整手，不产生碎股。
2. 每手股数以下单当天的证券资料为准。运营部在 10-30 收盘后和券商端证券资料核对一遍，如有变动当晚通知周衡和投资经理。
3. 股价最小变动单位按价格区间不同，投资经理下限价单时注意价位。

## 四、费用预估方法（下单阶段用）

1. 按建仓方案的建仓市值合计，粗算印花税约为 0.1%，其余法定费用合计约为万分之一，加上协议佣金。
2. 费用从港元现金里支付，不调整建仓股数。建仓方案里的现金是未扣交易费用的数字，下单后实际现金会略低，运营部在交收后把实际费用发投资经理和风控。
3. 冲击成本由交易室按分批下单控制，单只股票单日成交不超过该股前 20 日日均成交额的 10%，具体由交易室另行安排。

## 五、和其他环节的关系

- 建仓测算：不考虑交易费用和冲击成本，按基准日收盘价算建仓股数和现金。
- 期货对冲测算：使用建仓方案里的现金，交易费用的影响由风控在现金留存比例里统筹考虑。
- 估值：托管行按成交价和实际费用入账，估值从成立日开始。
