## 用的是哪个在线 MCP

US Stocks MCP，地址 `https://mcp-stocks-us.gino.im/mcp`，免注册，数据来自 Yahoo Finance。A 股、港股、美股代码都能查。配置在 `.cursor/mcp.json`，服务名 `us-stocks`。

在收题表里它属于「其他金融在线 MCP」。2026-11-11 已在项目群报备，项目组答复：MCP 选项选「其他金融在线 MCP」，在跨软件说明里写明名称和地址，从 MCP 拉取的数据文件直接传到题目附件。十二份填写稿都已按这个写法处理。

本机没有 Node，调用用的是 `_工具/mcp_call.py`：

```bash
cd finance/_工具
python3 mcp_call.py list us-stocks
python3 mcp_call.py call us-stocks get_historical_stock_prices '{"ticker":"300750.SZ","period":"1y","interval":"1d"}' --save 输出.json
```

`--save` 会把查询时间、服务地址、工具、参数和原始返回一起存下来，这个文件就是要上传的 MCP 结果文件。

这个服务的限制：

- 历史行情只能按 `period`（1mo、1y、5y 等）往回取，不能指定起止日期。
- 返回的收盘价按分红做过前复权，日期是 UTC 时间。A 股、港股要加 8 小时才是交易日；美股日期部分就是交易日。
- 没有国内期货合约。商品跨期原计划查合约的最后交易日，改成用上证指数核对交易日。
- A 股代码的后缀是 `.SS`、`.SZ`，用 `.SH` 查不到数据。公司信息用 `get_stock_info`，美股配对用它核对行业。

## 和底稿的差异

用公开接口预查时发现两处数据缺口，预取结果在 `_工具/预取/`，后来都用 MCP 确认了。这两处就是 02、04 两道题的查询内容，题面写明缺失日不补，所以标答数字和底稿相同。

- 02 招行分钟线缺 2026-07-06 整个交易日。口径说明写的是 81 个交易日，公开日线是 82 个。缺的这一天在预热期里，61 天的评估区间是齐的。
- 04 ETF 日线缺 2025-10-24，10 只 ETF 当天都有成交。

10、11、12 三道没有底稿：

- 行情由 `_工具/fetch_新题.py` 通过 MCP 实际查询，原始返回在 `_工具/新题数据/`。已经存过的文件不会重拉。
- 快照附件由打包脚本从原始返回生成，其中一项留给在线查询。
- 口径文件的原稿在 `_工具/新题口径/`。
- 持股数、权重、现金、限额是按题目需要拟的，不是真实持仓。要换成实际数字，改打包脚本开头或 `新题口径/` 后重跑，再同步改填写稿。
