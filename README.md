# 出题底稿

飞书高经济价值出题的本地底稿。已经做完材料的题放在 `cases/`。后续新题按参考案例的顺序另开目录。

参考案例：[cases/qqq_turtle_gate](cases/qqq_turtle_gate/README.md)

第二题：[cases/prop_account_choice](cases/prop_account_choice/README.md)，自营考试账户二选一。

第三题：[cases/au_lunch_gate](cases/au_lunch_gate/README.md)，沪金午休跟随是否上实盘。

出题口径以参考案例为准。2026-11-06 确认：满分 100 分，豆包 2.1 Pro 得分不超过 50；考点拆成 3 到 6 个维度，加总 100，每维 3 到 4 个可核对的等级，并写明易错点。标答文字要写裁定理由。细节在参考案例的「平台要求」「考点怎么写」「注意事项」。

下一题从这里开始：

1. 读参考案例里的「平台要求」「考点怎么写」「注意事项」和「下一题按这个顺序」。
2. 新建 `cases/<题目目录>/`，放输入附件、标答和一份说明。说明里写清决策、材料从哪来、正式结果、什么不要交给模型。
3. 标答用本地程序跑死，再写考点。题面里不放考点，也不放结果。
4. 用豆包 2.1 Pro 做正式自测。其他模型只能用来检查材料和题干。

`.env` 和 `cases/*/selftest/` 不入库。RSI 采集表的 PDF 留在本机，不属于这道案例。
