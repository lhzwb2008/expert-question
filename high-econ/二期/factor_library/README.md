# 量价因子入库检验

2026-11-11。二期第四题。60 只沪深大盘股上检验五个量价因子，决定哪些入库。

正式结果：只有 F3 低波动入库（IC 均值 0.0721，t 值 2.14，净多空月均 0.888%）。F4 的 IC 为正月数最多，但 t 值 1.19。

股票池是手工给定的 60 只，不代表任何指数成份。数据来自 Yahoo 复权日线，`fetch.py` 不需要账号。
