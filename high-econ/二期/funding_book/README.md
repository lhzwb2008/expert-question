# 永续资金费账本选择

2026-11-11。二期第一题。五个永续合约的资金费结算和现货小时线，决定哪一个可以做空永续、多现货的资金费账本。

## 要决定的事

最近 21 次费率的平均值达到 0.00004 才持仓。合格要净收益为正，且最大回撤不超过 400。合格的里面取净收益最高的。

正式结果：上 ETHUSDT，净收益 1419.81，最大回撤 286.83。DOGEUSDT 净收益 1621.63 是五个里最高的，但回撤 856.00。BTC 也合格，净收益 1303.50，低于 ETH。数字见 `标准结果.md`。

## 出题时定下来的几件事

- 门槛用 0.00004。WIF 的费率长期停在 0.00005，门槛放在 0.00005 时，21 次平均会有 444 次正好等于门槛，不同的浮点算法结果不一样。0.00004 没有一次相等。
- WIF 现货上市前的资金费没有放进 A01，题目里不用再讲缺价怎么办。
- WIF 是 4 小时结算一次，另外四个是 8 小时。A03 只说以实际时间为准。
- 回撤线 400 两边都留了距离：ETH 286.83，WIF 466.47。
