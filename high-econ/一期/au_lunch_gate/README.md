# 沪金午休跟随是否上实盘

2026-11-05。第三道题。材料来自 laplace 里 2026-10-27 提交的 `au_lunch.py`：沪金午休时伦敦金已经走出方向，13:30 按同方向进场，14:30 平仓。

## 要决定的事

自营交易台要决定：这套规则用 200,000 元实盘，上还是搁置。三条门槛都过才上。正式结果是期末权益 468,960.73 元，最大回撤 13.8427%，强平 5 次。前两条过，强平不过，结论是搁置。

不封顶强平的话，强平次数变成 0，回撤仍小于 15%，结论会翻成上实盘。数字见 `answer/标准结果.md`。

## 和前两题比，改了什么

- 场景换成国内期货。决策是上实盘或搁置，不是买哪家考试账户。
- 行情是两个市场：沪金 5 分钟线、伦敦金午休时段的 1 分钟线。模型要自己排夜盘交易日、选上一日成交量最大的合约、对齐午休涨跌。

## 没放进来的东西

没有天勤账号，没有伦敦金的拉取脚本。momentum、蝴蝶套利的参数和代码都没进附件。`rebuild.py` 不 import laplace 的策略代码。

沪金来自天勤免费行情，每张合约大约 1 万根，远月历史会被截断。伦敦金来自 Dukascopy 的公开 1 分钟线，只保留北京时间 11:00 至 13:40。附件里的数据就是全部证据。
