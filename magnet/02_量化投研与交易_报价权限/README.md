# 报价权限开通

Magnet 专用题，不从其他项目的计算题改。流程是逐人过六项书面规则，验证是对照三个数。

## 附件页

### 附件包

```
报价权限_附件包.zip
```

### 具体岗位

```
量化研究员
```

### 预计任务耗时（分钟）

```
600
```

### 任务范围与口径

```
只复核申请人表里的 16 人，评估日 2026-11-01。执照、额度、冷静期、跨产品资格和冻结以开通标准为准。产品上限和是否跨产品以产品表为准，资格以资格表为准。申请人表的同事预填不参与判断。不使用这些文件以外的执照、行情或权限记录。
```

### 业务背景

```
做市部要给一批研究员开报价权限。开通标准、产品上限和资格已经冻结，同事事先在申请人表最后一列填了开通或不开通。权限主管要求按书面标准逐人重判，再决定这批是签发还是搁置。
```

### 任务目的

```
确定这 16 人谁可以开通，并按三条门槛决定整批签发还是搁置。
```

### 具体任务要求

```
按开通标准逐人判断开通或不开通。不开通的只写一个原因，顺序按开通标准。用正式结论统计三个数，对照交付与签发文件里的三条门槛，给出签发或搁置。同事预填只放在台账里对照，不代入门槛。
```

### 交付物 1｜文档｜.docx

```
报价权限开通备忘录
```

```
先写签发或搁置。然后各写一次：正式开通人数、其中跨产品人数、冻结人员中被判为开通的人数，并写明对应门槛是否满足。三个数写错视同对应门槛不满足。
```

### 交付物 2｜表格｜.xlsx

```
报价权限逐人台账
```

```
每人一行：人员编号、正式结论、原因、是否跨产品、同事预填。开通的原因留空。不开通的原因只用开通标准里的六个词之一。
```

### 整体要求

```
备忘录里的正式开通人数，等于台账里结论为开通的行数。三个门槛数字和签发或搁置只在备忘录写一次。
```

### Query

```
【背景】
做市部要给 16 名研究员开报价权限。开通标准、产品上限和资格已经冻结。同事在申请人表最后一列预填了开通或不开通。权限主管要按书面标准逐人重判，用三个数决定这批是签发还是搁置。

【范围】
只复核申请人表中的人员，评估日、执照、额度、冷静期、跨产品资格和冻结以开通标准为准。产品上限和是否跨产品以产品表为准。跨产品资格和冻结以资格表为准。同事预填不参与判断，也不得因为该列开通人数更多就签发。不使用这些文件以外的执照、行情或权限记录。

【要求】
按开通标准逐人给出开通或不开通。不开通的只保留一个原因，顺序按开通标准。统计正式开通人数、其中跨产品人数、冻结人员中被判为开通的人数。三个数按交付与签发文件的三条门槛判定，三条都满足写签发，有一条不满足写搁置。三个数写错视同对应门槛不满足。

提交《报价权限开通备忘录.docx》《报价权限逐人台账.xlsx》。备忘录先写签发或搁置，三个数各写一次并写明门槛是否满足。台账每人一行，列明人员编号、正式结论、原因、是否跨产品和同事预填。备忘录的正式开通人数等于台账中结论为开通的行数。
```
