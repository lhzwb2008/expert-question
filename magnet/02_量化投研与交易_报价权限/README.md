# 报价权限开通

Magnet 专用题，不从其他项目的计算题改。流程是逐人过六项书面规则，验证是对照三个数。

### 任务范围与口径

```
只复核申请人表里的 16 人，评估日 2026-11-01。执照、额度、冷静期、跨产品资格和冻结以开通标准为准。产品上限和是否跨产品以产品表为准，资格以资格表为准。申请人表的同事预填不参与判断。不使用这些文件以外的执照、行情或权限记录。
```

### 业务背景

```
做市部要给一批研究员开报价权限。开通标准、产品上限和资格已经冻结，同事事先在申请人表最后一列填了开通或不开通。权限主管要求按书面标准逐人重判，再决定这批是签发还是搁置。
```

### 任务目的

```
确定这 16 人谁可以开通，并按三条门槛决定整批签发还是搁置。
```

### 具体任务要求

```
按开通标准逐人判断开通或不开通。不开通的只写一个原因，顺序按开通标准。用正式结论统计三个数，对照交付与签发文件里的三条门槛，给出签发或搁置。同事预填只放在台账里对照，不代入门槛。
```

### Query

```
【背景】
做市部这一批有 16 名研究员申请报价权限。开通标准、产品上限和人员资格已经冻结，申请人表最后一列是同事事先预填的开通或不开通。权限主管要求按书面标准逐人重判，用三个统计数决定这批权限签发还是搁置，复核结果交权限主管签批。

【范围】
只复核申请人表中的人员。评估日以及执照、产品、额度、冷静期、跨产品资格、冻结六项条件和原因顺序，以开通标准为准。产品上限和产品是否跨产品以产品表为准，跨产品资格和冻结状态以资格表为准，三条门槛和交付写法以交付与签发文件为准。同事预填不参与正式判断和门槛统计，也不得因为该列开通人数更多就写签发。不使用这些文件以外的执照、行情或权限记录。

【要求】
按开通标准逐人给出开通或不开通。不开通的只保留一个原因，多个原因同时成立时按开通标准规定的顺序取第一条。按正式结论统计正式开通人数、其中产品为跨产品的人数、资格表冻结人员中被判为开通的人数，逐条对照三条门槛：三条都满足写签发，有一条不满足写搁置。三个数写错视同对应门槛不满足。材料之间不一致时按上述来源取数，不用同事预填补齐。

【输出数量、名称、格式、具体要求】
请提交以下 2 份文件：
1. 《报价权限开通备忘录.docx》：开头先写签发或搁置；随后正式开通人数、其中跨产品人数、冻结人员中被判为开通的人数各写一次，每个数旁写明对应门槛是否满足。
2. 《报价权限逐人台账.xlsx》：每人一行，列明人员编号、正式结论（开通或不开通）、原因（开通留空，不开通只用开通标准里的六个词之一）、是否跨产品（Y 或 N）、同事预填。
备忘录的正式开通人数等于台账中正式结论为开通的行数。三个门槛数字和签发或搁置只在备忘录中写一次。日期写成 YYYY-MM-DD。
```
