### 任务范围与口径

```
生效日为 2020-09-07 至 2026-09-07，含两端。方向、费用和三个持有窗口以研究说明、事件与持有、开展标准为准。价格用不复权收盘价。快照里没有的代码使用供应商导出，先核对日期和复权口径。不使用这些文件以外的行情、汇率和指数公告。
```

### 业务背景

```
研究负责人要决定恒生指数成份股调整这套 A/H 交易做不做。被动资金在调整生效时买卖的是 H 股，A 股不在指数里。纳入和剔除的方向、持有天数和合格线已经冻结。内部行情快照没有覆盖全部代码，供应商另有日线导出。研究台要从成份股变动汇编里认出该做的变动，核对价格和汇率，把开展建议交给评审会表决。
```

### 任务目的

```
确定这套成份股调整交易开展或不开展。开展时写明持有天数，并说明三个窗口各自有没有通过合格线。
```

### 具体任务要求

```
从成份股变动汇编里确定考察期内纳入测算的变动，并对照公司代码。核对行情覆盖、汇率和供应商日线的日期与复权口径。按持有规则计算三个窗口的逐笔净收益和是否合格。按开展标准给出建议，各文件的笔数、净收益和结论保持一致。
```


### Query

```
【背景】
研究负责人要决定一套恒生指数成份股调整的 A/H 交易做不做。被动资金在调整生效时买卖的是 H 股。方向、持有窗口和合格线已经写在研究说明和开展标准里。内部行情快照没有覆盖全部代码，供应商另有日线导出。复核人依据成份股变动汇编、公司代码、行情快照、汇率和供应商导出完成测算，把开展建议、变动取舍表、事件测算表和行情核对记录交给评审会，用于表决这套交易做不做。

【范围】
生效日为 2020-09-07 至 2026-09-07，含两端。方向、费用和三个持有窗口以研究说明、事件与持有、开展标准为准。价格用不复权收盘价。快照里没有的代码使用供应商导出，先核对日期和复权口径。不使用这些文件以外的行情、汇率和指数公告。

【要求】
从成份股变动汇编里确定考察期内纳入测算的变动，并对照公司代码，说明不纳入的原因。核对行情覆盖、汇率，以及供应商日线的日期和复权口径。按持有规则计算三个窗口的逐笔净收益，并按开展标准判断每个窗口是否合格、这套交易开展或不开展。名称对不上、价格缺失或复权口径无法确认时，保留已确认事实，列出待核项及其对净收益和开展结论的影响，不用假设价格补齐。

提交《恒指调整开展建议.docx》《变动取舍表.xlsx》《事件测算表.xlsx》《行情核对记录.xlsx》，各文件的内容按开展标准的要求。四份文件中的笔数、净收益和结论保持一致；事件测算表里的每一笔都能在变动取舍表里找到纳入记录；关键判断能回指到附件中的记录或条款。
```
