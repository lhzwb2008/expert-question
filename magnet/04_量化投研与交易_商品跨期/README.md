### 任务范围与口径

```
对象为上期所、大商所、郑商所共十八个商品期货品种。评估期为 2023-01-01 至 2026-10-30，含两端，证据截止日 2026-10-30。行情字段、合约代码和交易日以行情说明为准，合约配对和年化展期以配对口径为准，是否纳入、方向和分年以准入标准为准。上证指数只用于核对交易日，不进入期限结构测算。策略组初筛只作对照，不作为结论依据。不使用这些文件以外的行情。
```

### 业务背景

```
商品研究台准备搭一个跨期价差组合，每个品种只做一对近月和远月合约。评审会定了品种准入标准，研究台写了配对口径，数据组导出了十八个品种全部合约的日线、合约规格和上证指数日线。策略组在评估期结束后用自己的脚本跑过一轮初筛，给了一份名单。评审会要求复核人按成文口径重新测算，决定哪些品种纳入组合和各自的方向，交代分年是否稳定，并说明与初筛名单的差别。
```

### 任务目的

```
按成文口径测算十八个品种的期限结构，决定纳入组合的品种和方向，说明分年稳定性以及与策略组初筛名单的差别。
```

### 具体任务要求

```
核对合约日线在评估期内的交易日是否齐全，写明各年交易日数和与上证指数的对照结果。按配对口径逐日配出各品种的近月和远月，得到十八个品种的四项指标和纳入结论。写明纳入品种的方向，以及只差一条标准未纳入的品种各自差在哪一条。按年给出各品种的四项指标，说明纳入品种是否每年都满足以及分年与全期不一致的原因。对照策略组初筛结果，写明两份名单的差别和差别来自初筛的哪一处做法。
```

### Query

```
【背景】
商品研究台准备搭一个跨期价差组合，每个品种只做一对近月和远月合约。评审会定了品种准入标准，研究台写了配对口径，数据组导出了十八个品种全部合约的日线、合约规格和上证指数日线；策略组在评估期结束后用自己的脚本跑过一轮初筛，给了一份名单。复核人依据这些材料重新测算，把准入意见、测算表和纳入品种逐日台账交给评审会，用于表决哪些品种进入组合。

【范围】
对象为上期所、大商所、郑商所共十八个商品期货品种。评估期为 2023-01-01 至 2026-10-30，含两端，证据截止日 2026-10-30。行情字段、合约代码和交易日以行情说明为准，合约配对和年化展期以配对口径为准，是否纳入、方向和分年以准入标准为准。上证指数只用于核对交易日，不进入期限结构测算。策略组初筛只作对照，不作为结论依据。不使用这些文件以外的行情。

【要求】
核对评估期内合约日线的交易日是否齐全，写明各年的交易日数和与上证指数的对照结果。按配对口径逐日配出每个品种的近月和远月，算出十八个品种的四项指标，逐条对照准入标准给出纳入结论和方向；未纳入的品种里只差一条标准的，逐个写明差在哪一条和对应数值。按年重算各品种的四项指标，说明纳入品种是否每一年都满足，以及分年结果与全期结论不一致的原因。对照策略组初筛结果，写明两份名单的差别，差别来自初筛的哪一处做法，并用数字说明。行情缺失、日期对不上或口径无法确认时，保留已确认事实，列出待核项及其对指标和纳入结论的影响，不用假设数据补齐。

【输出数量、名称、格式、具体要求】
请提交以下 3 份文件：
1. 《商品跨期品种准入意见.docx》：写明纳入的品种和各自的方向，逐条写明纳入品种四条标准的数值；写明只差一条标准未纳入的品种各自差在哪一条及对应数值；写明交易日核对的结论，纳入品种是否每一年都满足四条，分年结果与全期结论不一致的原因，以及复核名单与初筛名单的差别、差别来自初筛的哪一处做法和对应的数字。
2. 《商品跨期品种测算表.xlsx》：含四个工作表。品种判定表，十八个品种各一行，列出交易日数、配对日数、大波动日数、正号天数、负号天数、配对覆盖率、大波动日占比、方向占比、年化展期中位数、四条标准各自是否满足、是否纳入和方向；分年判定表，每个品种每年一行，列同品种判定表；初筛对照表，十八个品种各一行，列出初筛和复核各自的配对日数、大波动日数、方向占比、中位数和结论，标明结论是否一致；交易日核对表，列出各年上证指数的交易日数、合约日线的交易日数和是否一致。
3. 《商品跨期纳入品种逐日台账.xlsx》：纳入品种在评估期内每个配对日一行，列出品种、交易日、近月和远月的合约代码、收盘价、最后交易日，两个最后交易日相隔的自然日数和年化展期；另附配对变更表，每个纳入品种按时间列出每一段近月远月组合的合约代码、起止交易日和配对日数，近月或远月任一变更即另起一段。
三份文件里的纳入名单和方向一致；逐日台账的行数等于品种判定表里纳入品种的配对日数之和；分年判定表各年的交易日数、配对日数、大波动日数之和等于品种判定表的全期数；关键数字能回指到附件中的记录或条款。日期写成 YYYY-MM-DD，比例、年化展期和中位数保留 6 位小数。
```
