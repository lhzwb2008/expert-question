### 任务范围与口径

```
回放区间为伦敦日期 2025-01-02 至 2026-10-30。行情使用数据组存档的买价、卖价分钟线，进入回放的分钟范围以背景与术语文件为准。四个方案各自使用新账户，起始资金和方案差异以方案文件为准。受限事件的范围以新闻交易规则为准。比较时间前先换算到同一时区。行情和日程截止 2026-10-30，不另取归档以外的行情、日程或账户条款。
```

### 业务背景

```
P平台资助账户准备接入一台英镑兑美元日内机器人。账户对重大新闻发布前后的开仓和平仓有限制，违规交易的盈利会被扣除，累计达到规定次数后账户终止。这台机器人目前不能识别新闻。上线前，风控要用数据组存档的买价、卖价分钟行情、机器人策略、账户的新闻交易规则和三家机构官网的发布日程，先核对行情，再回放四个过滤方案并逐日比较，把建议交给自营交易负责人，决定交易系统按哪一方案接入。
```

### 任务目的

```
确定上线时采用的新闻过滤方案，说明各方案在账户规则下的交易结果、违规处理和账户状态，以及方案之间的差异来自哪些日期和事件，供负责人决定交易系统如何接入。
```

### 具体任务要求

```
核对买价、卖价分钟行情存档，确定进入回放的分钟和每个交易日的开仓条件。依据新闻交易规则，从三份官方日程确定受限事件，并换算到同一时间基准。按机器人策略分别回放四个过滤方案，统计交易、违规、扣除盈利和账户状态。逐日比较四个方案的交易差异，说明差异对应的受限事件和利润差额来源。按方案文件的比较方法给出采用建议，五份文件的笔数、违规和利润保持一致。
```

### Query

```
【背景】
自营交易负责人委托风控，在 P 平台资助账户接入 GBP/USD 日内机器人之前完成复核。账户对重大新闻发布前后的开仓和平仓有限制，当前版本的机器人不识别新闻。已提出四个过滤方案。归档目录里有数据组存档的买价、卖价分钟行情、机器人策略、账户的新闻交易规则、三家机构官网的发布日程，以及方案和交付要求。风控先核对行情，再回放四个方案并逐日比较，把结果交给负责人，用于决定交易系统按哪一方案接入。

【范围】
回放区间为伦敦日期 2025-01-02 至 2026-10-30。行情存档按买价、卖价和年份分开，进入回放的分钟范围以背景与术语文件为准。四个方案各自使用新账户，起始资金和方案差异以方案文件为准。受限事件的范围以新闻交易规则为准。比较时间前先换算到同一时区。行情和日程截止 2026-10-30，不另取归档以外的行情、日程或账户条款。每日最大亏损、账户最大亏损和最少交易天数不在本次复核范围内。

【要求】
核对行情存档：各文件的覆盖范围、买卖两侧是否对应、进入回放的分钟和交易日，并逐日确定是否具备开仓条件。按新闻交易规则从三份官方日程确定受限事件，列明美国东部时间、伦敦时间和 UTC。按机器人策略分别回放四个方案，统计交易、违规、被扣除的盈利、可提现利润和账户是否终止。逐日比较四个方案的交易，说明差异对应的受限事件，以及期末仍存续的方案之间利润差额的来源。按方案文件中的比较方法给出采用建议和依据。行情记录、发布时刻或时区无法确认时，保留已确认事实，列出待核项及其对违规判断和方案比较的影响，不用假设补齐。

提交《新闻过滤方案建议书.docx》《受限事件表.xlsx》《逐笔台账.xlsx》《行情核对记录.xlsx》《方案差异清单.xlsx》，各文件的内容按方案与交付文件的要求。五份文件中每个方案的交易笔数、违规笔数、可提现利润和最终选择保持一致；差异清单里的每个日期都能在逐笔台账和受限事件表里找到对应记录；关键判断能回指到附件中的记录或条款。
```
