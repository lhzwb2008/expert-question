### 任务范围与口径

```
标的为上海期货交易所黄金期货，方向来自伦敦金午休时段的涨跌。考察期为 2021-10-30 至 2026-10-30，按交易日计，含两端，证据截止日 2026-10-30。交易日归属和行情字段以行情说明为准，合约、信号、成交和仓位以策略说明为准，保证金、费用、强平和回撤以账户与费用为准，是否上实盘只按上线标准。COMEX 金价只用于分年对照，不进入交易重算。不使用这些文件以外的行情。
```

### 业务背景

```
期货策略组提交了一套沪金午休跟随规则，准备用 200,000 元在自营交易台实盘运行。规则在沪金午间休市结束后，按伦敦金午休期间的涨跌方向进场，当天平仓。策略说明、账户与费用口径和上线标准已经成文，沪金、伦敦金和 COMEX 黄金期货的行情由数据组导出。评审会要求复核人只依据这些材料重算考察期内的成交和权益，对照上线标准给出上实盘或搁置的意见，并交代盈利的年份分布和同期金价的关系。
```

### 任务目的

```
按成文口径重算这套规则在考察期内的逐笔成交、权益、回撤和强平，对照上线标准决定上实盘或搁置，并说明盈利的年份分布和同期金价涨跌的对照。
```

### 具体任务要求

```
确定考察期内的交易日和每个交易日所做的合约，核对沪金与伦敦金行情的覆盖情况。按策略说明和账户口径重算每笔成交的方向、手数、盈亏、平仓后权益和强平。逐条对照上线标准给出上实盘或搁置的结论，并写明各项统计和强平发生的交易日。汇总分年和分合约的结果，计算同期 COMEX 黄金期货涨跌幅并与分年盈亏对照。三份材料中的期末权益、成交笔数、强平次数和结论保持一致。
```

### Query

```
【背景】
期货策略组提交了一套沪金午休跟随规则，准备用 200,000 元在自营交易台实盘运行：沪金午间休市结束后，按伦敦金午休期间的涨跌方向进场，当天平仓。规则、账户与费用口径和上线标准已经成文，沪金 5 分钟线、伦敦金午休 1 分钟线和 COMEX 黄金期货日线由数据组导出。复核人依据这些材料重算考察期内的成交和权益，把上线评估意见、逐笔台账和交易日核对表交给评审会，用于表决这套规则上实盘还是搁置。

【范围】
考察期为 2021-10-30 至 2026-10-30，按交易日计，含两端，证据截止日 2026-10-30。交易日归属和行情字段以行情说明为准，合约、信号、成交和仓位以策略说明为准，保证金、费用、强平和回撤以账户与费用为准，是否上实盘只按上线标准。COMEX 金价只用于分年对照，不进入交易重算。不使用这些文件以外的行情。

【要求】
确定考察期内的交易日和每个交易日所做的合约，核对沪金与伦敦金行情的覆盖情况，每个没有成交的交易日写明原因。按策略说明和账户口径重算每笔成交的方向、手数、盈亏、平仓后权益和强平。逐条对照上线标准给出上实盘或搁置的结论，写明各项统计和强平发生的交易日，并说明强平是在什么情况下发生的。汇总分年和分合约的结果，计算同期 COMEX 黄金期货涨跌幅，说明盈利的年份分布，以及它和金价涨跌有没有对应关系。行情缺失、时间对不上或口径无法确认时，保留已确认事实，列出待核项及其对权益、强平次数和结论的影响，不用假设价格补齐。

【输出数量、名称、格式、具体要求】
请提交以下 3 份文件：
1. 《沪金午休上线评估意见.docx》：写明上实盘或搁置，逐条写明三条标准是否满足及对应数值。写明期末权益、总收益、最大回撤及其高点日和谷底日、成交笔数、多空笔数、盈亏笔数、强平次数和每次强平的交易日，并说明盈利的年份分布与同期金价涨跌的对照。
2. 《沪金午休逐笔台账.xlsx》：每笔成交一行，列出交易日、合约、方向、手数、开仓价、平仓价、伦敦金午休涨跌、盈亏、平仓后权益、是否强平；另附分年汇总（笔数、当年盈亏、年末权益、同期 COMEX 涨跌幅）和合约汇总（首末成交的交易日、笔数、盈亏合计）。
3. 《沪金午休交易日核对表.xlsx》：考察期内每个交易日一行，列出交易日、当天所做的合约、伦敦金起点价和终点价、午休涨跌、是否成交、未成交的原因；另附汇总，写明交易日数、成交的天数和各类未成交原因的天数。
三份文件中的期末权益、成交笔数、强平次数和结论保持一致；逐笔台账的每一笔都能在交易日核对表里找到对应的成交日；分年汇总的各年盈亏之和等于期末权益减初始资金；关键数字能回指到附件中的记录或条款。日期写成 YYYY-MM-DD，金额保留两位小数。
```
