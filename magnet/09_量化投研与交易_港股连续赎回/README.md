### 任务范围与口径

```
研究对象为既有十二只港股研究组合，不代表实盘持仓。静态基准日为2026-10-30；连续回款研究以2026-09-30收盘后的同组证券数量起步，成交回放为2026-10-02至2026-11-06，既有交收处理至2026-11-10。只使用附件中的行情快照、研究假设和公开规则，按回放时点限制可用信息。分别测算10%、20%、30%、50%四档连续申请及0.05至1.50倍规模网格；批次目标、共享额度、尾单、费用分摊、交收及周度期限均以研究口径为准。款项按篮子实际净回款划付，不解释为按基金份额净值计价的赎回承诺。既有静态成品仅作对照，不能替代连续回放。
```

### 业务背景

```
产品研究已有一份港股持仓变现能力静态测算，但单次按比例卖出需要的天数，不能直接说明连续受理申请时每批资金何时到账。当前需要在真实历史成交量和收盘价快照上，把相邻申请对同一股票的竞争、未完成目标的证券预留、整批及尾单成本、交收回款串起来，并识别周度安排可支持的组合规模。研究中的组合数量和执行参数属于公开注明的分析假设，不是客户委托或券商回单。复核结果用于产品开放方案讨论，不作为实际支付承诺。
```

### 任务目的

```
核实既有静态测算，形成连续申请的证券与现金证据链，判断原规模是否支持约定回款期限，并反推网格内可支持规模及其边界，说明研究结论的适用限制。
```

### 具体任务要求

```
1. 核验行情时区与价格口径，复核静态变现阶梯及既有测算差异。
2. 列明四档连续申请的目标预留、共享额度、成交分配和期末证券。
3. 完整列示逐单费用、批次分摊、交收回款及全部现金勾稽结果。
4. 给出全规模网格的批次结果、周度可支持规模及相邻不可行点。
5. 提交一致的评估意见和复核台账，解释结论差异及研究适用边界。
```

```
【范围】

【要求】
核验日期时区、价格和成交量口径，复核静态能力与变现阶梯，说明既有测算是否成立。形成各档连续申请的完整目标、成交、持仓、费用、交收和现金证据链，区分未成交证券、应收交收款、已到账现金与已划付资金。对全规模网格给出批次结果和周度可支持规模，保留可行边界的完整复核记录，并说明与原规模和既有静态结论的差异。结论依赖的行情或规则无法确认时，保留已确认事实，列待核项及其影响，不补造数据。不要将研究执行单位和客户收费假设写成交易所强制要求，也不要把未来制度路线图视为已经生效。

3.《港股连续申请与成交复核台账.xlsx》：原规模四档含目标预留、每日每股容量、汇总成交单、批次分配和每日证券。列各项容量约束、执行路线、成交价量、六项费用、交收日及实际/预留/自由证券；无成交日仍保留容量和证券。
```
