# 赎回划付安排

Magnet 专用题，不从其他项目的计算题改。流程是逐笔定划付日，验证是对照三个数。

赎回划付_附件包.zip
```

### 具体岗位

```
量化风控分析师

### 预计任务耗时（分钟）

```
600
```

### 任务范围与口径

```
只安排预约表里的 10 笔。金额、巨额和正式划付日以划付标准为准。基金规模、单日现金和向后数的天数以基金表为准。工作日只认工作日表里标记为 Y 的日期。预约表的同事划付日不参与正式划付日和超限统计。不使用这些文件以外的行情、净值或假日。
```

### 业务背景

```
专户要把 10 笔赎回安排到具体划付日。划付标准和基金参数已经冻结，预约表上另有一列同事留下的划付日。资金岗要按书面标准重排，再决定这批划付是签发还是搁置。
```

### 任务目的

```
确定每笔赎回的正式划付日，并按三条门槛决定整批签发还是搁置。
```

### 具体任务要求

```
按划付标准计算每笔金额、是否巨额和正式划付日。用正式划付日统计超限划付日个数、巨额笔数、正式划付日不是工作日的笔数。三个数对照交付与签发文件的三条门槛，给出签发或搁置。同事划付日只放在台账里对照。
```

### Query

```
【背景】
专户要把 10 笔赎回安排到具体划付日。划付标准和基金参数已经冻结。预约表上有一列同事留下的划付日。资金岗要按书面标准重排，用三个数决定这批划付是签发还是搁置。

【范围】
只安排预约表中的赎回。金额、巨额和正式划付日以划付标准为准。基金规模、单日现金和向后数的天数以基金表为准。工作日只认工作日表中标记为 Y 的日期。同事划付日不参与正式划付日，也不参与超限统计。不使用这些文件以外的行情、净值或假日。

【要求】
按划付标准逐笔计算金额、是否巨额和正式划付日。统计超限划付日个数、巨额笔数、正式划付日不是工作日的笔数。三个数按交付与签发文件的三条门槛判定，三条都满足写签发，有一条不满足写搁置。三个数写错视同对应门槛不满足。按同事划付日会把部分金额叠到另一天，这种超限不得当作正式结果。

提交《赎回划付备忘录.docx》《赎回划付逐笔台账.xlsx》。备忘录先写签发或搁置，三个数各写一次并写明门槛是否满足。台账每笔一行，列明预约编号、金额、是否巨额、正式划付日和同事划付日。备忘录的巨额笔数等于台账中是否巨额为 Y 的行数。
```
