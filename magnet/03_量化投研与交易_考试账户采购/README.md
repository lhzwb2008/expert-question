
### 任务范围与口径

```
开考日为美东时间 2024-01-03 至 2026-10-30 的每个交易日。策略、费用、杠杆和成交以策略说明为准。两家阶段规则以各自的规则备忘为准。成功率和采购比较以测算说明为准。同事的摘要不替代冻结规则。不使用这些文件以外的行情和账户条款。
```

### 业务背景

```
交易部要在下个月的考试账户采购里定一家。候选是 Aqua 的 Pay Later 200K 和 FTMO 的 2-Step 100K，上面跑同一套 QQQ 日内机器人。买错会把考试费和几个月时间押在更难拿到第一笔可提现的那家。同事已经按自己的做法给过结论。这次用冻结的规则重算成交和账户状态，把建议交给交易负责人拍板。
```

### 任务目的

```
确定下个月购买哪家考试账户，说明两家拿到第一笔可提现的可能性、失败出在哪个阶段，以及和同事那版差在哪里。
```

### 具体任务要求

```
核对分钟行情的覆盖、提前收盘和缺失分钟，确定可以开考的交易日。按策略和两家规则，从每个开考日测算到首次可提现或违规。对照同事的测算，说明成功率和采购结论差在哪一项处理。按测算说明的比较方法给出采购建议，各文件的笔数和结论保持一致。
```

### Query

```
【背景】
交易负责人要在下个月的考试账户采购里定一家。候选是 Aqua Pay Later 200K 和 FTMO 2-Step 100K，上面跑同一套 QQQ 日内机器人。阶段规则、策略和成交约定已经冻结。同事按自己的做法提交了测算说明和摘要。复核人依据分钟行情、交易环境、策略、两家规则和测算说明重算，把采购建议、逐开考日台账、行情核对记录和测算差异清单交给负责人，用于决定购买哪家。

【范围】
开考日为美东时间 2024-01-03 至 2026-10-30 的每个交易日。策略、费用、杠杆和成交以策略说明为准。两家阶段规则以各自的规则备忘为准。成功、失败、未结束和采购比较以测算说明为准。与同事的说明或摘要不一致时，以冻结的策略和规则为准。不使用这些文件以外的行情和账户条款。

【要求】
核对分钟行情的覆盖、提前收盘和缺失分钟，确定可以开考的交易日。按策略和两家规则，从每个开考日测算到首次可提现或违规，统计成功、失败、未结束、成功率和成功耗时。对照同事的测算，说明成功率和采购结论差在哪一项处理，并列出两家正式结果不相同的开考日。按测算说明的比较方法给出采购建议。行情缺失或规则条款无法确认时，保留已确认事实，列出待核项及其对成功率和采购结论的影响，不用假设补齐。

提交《考试账户采购建议.docx》《逐开考日台账.xlsx》《行情核对记录.xlsx》《测算差异清单.xlsx》，各文件的内容按测算说明的要求。四份文件中的成功数、失败数、未结束数和采购结论保持一致；差异清单里的每个开考日都能在逐开考日台账里找到对应记录；关键判断能回指到附件中的记录或条款。
```
