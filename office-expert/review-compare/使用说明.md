# 作业标注对比插件 1.3.0

适用于桌面 Chrome / Edge。插件内部打开独立对比窗口，无需运行服务器。

## 安装或更新

解压压缩包。打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，加载包含 `manifest.json` 的“作业标注对比插件”文件夹。

已安装用户：将新版文件覆盖到原插件目录，在扩展管理页点击“重新加载”，关闭旧对比窗口后重新打开。原目录更新会保留快照和核实记录。旧版已选定的最终分数与备注会转换为统一答案；没有最终选择的旧草稿仍需补齐。

更换安装文件夹时，浏览器可能视为另一个插件。先在旧版导出快照 JSON，再在新版导入。

## 保存作业内容

1. 打开 a 表，选择包含“题目ID”、全部模型的人评表头和需要的题目行的完整区域，按 Ctrl+C。不同期表格列位置可能不同，请按实际表头选择。
2. 在该页面点击插件图标，选择“保存剪贴板到 A”。
3. 打开 b 表，同样复制包含题号、全部人评表头和题目行的区域，在该页面点击插件图标，保存到 B。
4. 插件根据“模型名-人评”自动识别人评列，也支持“－”和“—”分隔符；只复制 JSON 时按 JSON 的 model 识别。保存后核对 A/B 的模型数量和名称，再按题号、模型、维度 ID 对齐。

模型数量不固定，两侧可以不同。仅一侧保存内容包含的模型标记为“仅单侧模型”，已有数值评分可直接沿用、也可选填修改，不计为差异或真实缺项。两侧都声明了同一模型，但某侧标注为空、某维度缺失或未给分，仍需核实。两侧都空的标注无法生成完整 JSON，导出会提示补齐。

没有题号列时，插件会从同一行其他人评 JSON 推断题号；整行都空则无法推断，请包含题目ID。旧版内置 Q001～Q010 的 AI:AU 快照继续兼容。其他期不按行号猜题号，也不默认补齐四个模型。重复模型、题号冲突、表头与 JSON 模型不一致及截断内容会提示错误。仅两组已知名称别名可自动匹配，导出保留原始 JSON 模型名。

飞书表格使用画布显示单元格，请使用复制区域方式。也可以通过“粘贴内容到 A/B”输入完整 JSON 或表格区域。超过 20,000 字符时仅预览前 2,000 字符，完整内容仍保留并参与对比。

“查看本次作业复核”提供 2026-11-13 重新读取的两表快照，覆盖 Q001～Q010，共 80 份标注、444 对维度，123 项分数不同、12 项缺项。这是读取时的快照；更新需重新复制保存。

## 统一答案

展开任意维度，底部只有一份“统一分数”和“评分理由”。分数不同或缺项时，填写核实结果并点击“确认统一答案”；原分一致时为选填。

- 分数不同或缺项：分数为 0～5，理由必填；编辑后需确认才能导出，修改已确认答案后需重新确认。
- 原分一致：分数和理由均选填。未填写分数则沿用一致原分，未填写理由则保留原始理由；填写的内容自动保存，导出直接采用，不要求点击确认。全部清空可恢复为沿用原分和原始理由。
- 仅单侧模型：按与一致项相同的选填规则导出已有原评分；这是复制来源的模型清单差异，请先核对是否漏复制了人评列。
- A/B 原始分数与证据保留在两侧供核实，不会被编辑覆盖。
- 评分总览包含该题全部模型和维度的统一分数、理由与确认状态；“查看 / 核实”可以跳转到对应维度。

## 底部 CSV 导出

在工具最底部选择题号，点击“导出核实评分 CSV”。文件名只保留题号，例如 `Q001.csv`。

本题分数不同或缺项的维度全部确认后即可导出；否则提示尚未确认的差异项。一致维度不影响导出：填写则采用填写内容，未填写则沿用一致原分与原始理由。导出始终包含本题全部模型、全部维度，不受“仅分数不同”、搜索或模型筛选影响。

文件只有以下列：

| 列 | 内容 |
|---|---|
| 题目ID | 所选题号，如 Q001 |
| 实际识别的各模型人评列 | 每列一个完整人评 JSON，保留来源表头名称 |

人评列顺序优先采用 B 的表头顺序，再追加 A 独有模型。两个来源的模型合并导出，不存在的模型不自动补列；仅一个模型时就是“题目ID＋一个人评列”。两期模型集合不同，导出可能同时包含两期独有的模型，写回时按各表实际列名选择对应单元格。

每个人评 JSON 保持 `human-eval/1`、`case_id`、`model`、`rubric_id` 和完整 `criteria` 结构。差异与缺项的 `score`、`note` 为已确认的统一分数及理由；一致项分别采用选填值或原始分数、理由。`status` 为 `scored`。其他字段及证据保留原始标注内容，优先使用 B，缺失时使用 A。如果还有其他模型，也会保留其对应的人评列。

CSV 使用 UTF-8 BOM，正确转义中文、逗号、引号和换行。只有题号和人评数据，不包含差异列、统计数据、两人独立意见或汇总行。

## 写回作业表

将 CSV 导入为临时电子表格，按“题目ID”定位原作业行，把各人评单元格中的完整 JSON 按列名写入对应模型的人评列。原表其他列不在导出文件中。人评列之间可能有其他原始列，请逐列对应，不要把 CSV 连续粘贴到原表。

本次提供的是可写回的文件格式，插件不直接修改飞书作业表。

## 保存其他网页与跨浏览器查看

在来源页面点击插件图标，选择“保存页面到 A/B”。有选中文字时保存选区，否则保存已加载文字；右键选区也可保存到 A。画布、图片、视频和未加载内容不包含在文字快照中。

同一浏览器切换页面后，保存内容仍可查看。不同浏览器使用“导出快照 / 导入快照”传递 JSON，其中包含原始文本、统一答案及核实状态。快照 JSON 用于继续核实，底部 CSV 用于写回。

## 清空与本地数据

“清空 A / B”或“清空全部缓存”会同时清除对应内容及统一答案，清空后刷新不会恢复。已导出的文件不会被删除。安装包自带的作业样本仅在明确点击载入时读取。

替换任一侧原始内容会清除旧核实记录，避免套用旧视频结论；重复载入完全相同的来源会保留记录。导入时重新解析原始文本，并校验核实记录所对应的原始维度。

内容仅保存在浏览器本地，不上传服务器。读取网站时仅申请当前来源网站访问权限。每侧文本上限 12 MB，快照包上限 30 MB。
